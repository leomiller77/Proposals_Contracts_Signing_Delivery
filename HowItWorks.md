# How Pactiamo Works

The workflow is designed to be as fast as possible, so you can spend less time on paperwork and more time doing actual work.

## Step 1: Describe the Project
Enter a single sentence describing your gig. For example: "Brand website redesign for eight thousand dollars with three milestones." The system will output a professional proposal and a matching contract.

## Step 2: Polish the Details
Use the visual editor to rearrange pricing tables, adjust terms, and add your branding. The output is print quality and client ready.

## Step 3: Send One Link
Generate a secure link and send it to your client. You can optionally protect it with a password and set an expiration date.

## Step 4: Track and Close
Watch the dashboard to see when the client opens the link. The client views the document, signs it without creating an account, and sees your payment link the moment the signature is finalized.
